# RachitOS // Cyberpunk Unix Developer Portfolio OS

RachitOS is a futuristic Linux/Unix-inspired personal operating system portfolio built for **Rachit Joshi** (Backend / Systems / Cloud / AI Experiments). It features **dual navigation**: a full visual UI with clickable panels and launcher shortcuts alongside a functional, stateful client-side CLI terminal.

---

## 🌟 Key Features

### 1. Dual Navigation Engine
- **Visual Desktop GUI**: Left vertical launcher rail, persistent system status top bar, and live HUD telemetry panel.
- **Functional CLI Terminal**: Interactive Unix REPL supporting `ls`, `cd`, `pwd`, `cat`, `tree`, `neofetch`, `git log`, `projects`, `about`, `experience`, `resume`, `contact`, `ping`, `whoami`, `sudo`, `matrix`, `404`, `coffee`, `clear`, and `exit`.

## 🛠️ Getting Started

### Prerequisites
- Node.js v20+
- npm / yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Rachit2912/portfolio-os.git
cd portfolio-os

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
